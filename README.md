# Contract Review Prototype

An experimental prototype that summarizes a contract and answers questions about it, using Claude. Paste a contract, get a plain-language summary (parties, term, payment, termination, liability, red flags, and missing or unclear points), then ask follow-up questions. Answers quote the clause they rely on, and each quote is marked as verified only if it appears in the contract (ignoring whitespace and smart-quote differences).

> **Experimental prototype. Not legal advice.** The output is general information generated by AI. It is not a lawyer and does not create an attorney-client relationship. Check anything important with a qualified attorney before you sign or rely on it. Don't paste confidential or personal data.

## What it does

- **Summary**: one card per field, plus red flags and a "Missing or unclear" section that lists standard clauses the text lacks and conflicts between clauses. The model is told to say when something isn't in the text rather than guess.
- **Q&A**: answers come only from the contract. Quotes are checked against the original text.
- **Access**: the full app sits behind a password. A public demo uses a built-in sample contract, with rate limits.
- **Storage**: contract text is sent to the Anthropic API for processing and is not written to disk, a database, or cookies by this app. Your use is subject to Anthropic's data policies.

## Requirements

- Node.js 20 or newer
- An Anthropic API key

## Run it locally

```bash
npm install
cp .env.example .env.local
```

Edit `.env.local` and set both variables (see below), then start the dev server:

```bash
npm run dev
```

Open http://localhost:3000, enter the password from `APP_PASSWORD`, and paste a contract. Use `npm run build && npm start` for a production build.

## Environment variables

Set these in `.env.local` for local development, or in your host's environment settings. Never commit `.env.local`.

| Name | Required | Purpose |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Yes | Read on the server only. Used to call the Anthropic API. |
| `APP_PASSWORD` | Yes | Password for the login form. Checked on the server only. If it is unset, the app refuses all access, including the demo. |

## Demo mode

On the login screen, **Try the demo** opens the app with a fictional sample contract already loaded and locked. The server accepts a request without a password only when the contract matches the sample exactly, and demo chat is instructed to answer only about that sample. Demo requests are limited to 50 per day in total and 5 per IP address per hour. The limits are kept in memory, so they reset when the server restarts.

## Known limits

- Rate limits for login and demo use in-memory state. They are not shared across server instances.
- Session cookies are `secure`, so they only work over HTTPS. Browsers treat `localhost` as a secure origin, so local development works over `http://localhost`.
- The app is marked `noindex, nofollow` so search engines don't index it.
